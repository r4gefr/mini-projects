# NumGuessing

A beginner-friendly number guessing game built with Python. The project helps practice conditions, loops, user input, and basic game logic in a fun way.

## Features

- Random number guessing gameplay
- Interactive terminal-based user input
- Simple and clear program flow
- Great for Python beginners
- Can be extended with score tracking or difficulty levels

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/r4gefr/python-mini-projects.git
   ```

2. Open the project folder:
   ```bash
   cd python-mini-projects
   ```

3. Navigate to the NumGuessing project folder.

4. Run the Python file:
   ```bash
   python your_file_name.py
   ```
