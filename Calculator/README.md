# Calculator

Simple command-line calculator in Python.

## Features
- Supports: `+`, `-`, `*`, `/`, `%`, `//`, `**`
- Handles integer and float input
- Guards against division/modulo/floor-division by zero
- Menu-driven, keeps running until you exit

## Requirements
- Python 3

## Run
```
python calculator.py
```

## How to Use
| Option | Operation |
|---|---|
| 1 | Addition (+) |
| 2 | Subtraction (-) |
| 3 | Multiplication (*) |
| 4 | Division (/) |
| 5 | Modulo (%) |
| 6 | Floor Division (//) |
| 7 | Power (**) |
| 0 | Exit |

Enter the option number, then two numbers when prompted.
