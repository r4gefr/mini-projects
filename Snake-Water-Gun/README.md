# Snake, Water, Gun

Command-line "Snake Water Gun" game (Rock-Paper-Scissors variant) in Python.

## Rules
- Snake drinks Water → Snake wins
- Water damages Gun → Water wins
- Gun shoots Snake → Gun wins

## Features
- Play unlimited rounds against the computer
- Tracks Wins, Losses, Ties, and running Score after each round
- Final summary printed on exit

## Requirements
- Python 3

## Run
```
python program.py
```

## How to Play
| Input | Choice |
|---|---|
| 1 | Snake |
| 2 | Water |
| 3 | Gun |
| 0 | Quit |

Computer picks randomly (1-3) each round.
