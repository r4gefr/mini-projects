# To-Do List Project 

A simple to-do list application built in Python to manage daily tasks. This project is useful for understanding task-based logic, list operations, and beginner-level project organization.

## Features

- Add new tasks
- View existing tasks
- Manage task workflow
- Beginner-friendly project setup
- Good base for advanced features like task status or deadlines

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/r4gefr/mini-projects.git
   ```

2. Open the repository folder:
   ```bash
   cd mini-projects
   ```

3. Open the `To-Do List Proj` folder.

4. Run the project file:
   ```bash
   python To-Do List.py
   ```

## Tech Stack

- Python

- Console-based task management
