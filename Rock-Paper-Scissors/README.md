# Rock, Paper, Scissors

Simple command-line Rock, Paper, Scissors game in Python.

## Features
- Play unlimited rounds against the computer
- Number-based input (1/2/3) for quick play
- Type 'exit' anytime to quit

## Requirements
- Python 3

## Run
```
python game.py
```

## How to Play
| Input | Choice |
|---|---|
| 1 | Rock |
| 2 | Paper |
| 3 | Scissors |
| exit | Quit game |

Computer picks randomly each round. Standard rules apply: Rock beats Scissors, Scissors beats Paper, Paper beats Rock.
